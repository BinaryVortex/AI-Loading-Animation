# AI Loading Animation

An elegant, lightweight AI-themed loading animation built with HTML, CSS and JavaScript.

![Demo screenshot](./Screenshot%202024-09-29%20194820.png)

---

## Demo

Open `index.html` in your browser (or host the project) to see the loading animation in action.

## Features

- Smooth, modern AI-style loading animation
- Pure HTML, CSS and a tiny bit of JavaScript — no frameworks or build tools required
- Easy to customize colors, size and animation timing

## Technologies

- HTML
- CSS (flexbox, transforms, keyframes)
- JavaScript (small script to control animation state)

## Installation / Usage

1. Clone the repository or download the ZIP:

   git clone https://github.com/BinaryVortex/AI-Loading-Animation.git

2. Open `index.html` in your browser. That's it — the animation runs with no build step.

## Customization

- Colors: Edit the CSS variables or the color values in `styles.css`.
- Size: Adjust width/height values in the CSS for the main container.
- Speed: Change the `animation-duration` values on the keyframes to speed up or slow down the effect.

Example (in `styles.css`):

```css
:root {
  --accent: #7c4dff; /* change this to update the main color */
  --bg: #0f1724;      /* background color */
}
```
